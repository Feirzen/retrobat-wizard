START HERE
==========

This folder is the RetroBat Wizard: the small program that sets RetroBat up,
keeps it working, and adds friends, an online game library and saves backups.
Everything else in the RetroBat folder is plain RetroBat.

You never need to open this folder to play. Use the two buttons in the
RetroBat folder:

    PLAY.bat                 checks everything is fine, then starts RetroBat
    RetroBat Wizard.bat      opens the wizard (its name follows Settings\wizard.ini)


AFTER A RETROBAT UPDATE
-----------------------
Press PLAY. The wizard notices the update and puts its settings back by itself.
(Buttons\RUN THIS AFTER AN UPDATE.bat does the same by hand.)


WHAT IS IN HERE (eight rooms, one job each)
------------------------------------------

  Program\    the wizard itself. Updates replace it. Never edit anything in
              here: a wizard update would put it back.
  Settings\   this setup's choices: the on/off switches (features.ini),
              controllers, the family-friendly list, each computer's picture
              quality, the wizard's name. Updates never overwrite these.
  People\     profiles, friends, play time, favourites, each person's saves,
              the browser games' own save data.
  Backups\    save backups (Saves\), Steam backups, and Archive\, where the
              wizard keeps a copy of anything it ever changed.
  Buttons\    one-click fixes, if you ever want to run one step by itself.
              Show Help.bat explains the whole thing in one page.
  Apps\       helper programs (ffmpeg, the browser games' launchers).
  Owner\      the admin's own things. Never shared.
  Cache\      safe to empty at any time; it all comes back by itself.
              Logs are in Cache\logs (wizard.log is the main one), and
              Cache\Trash is where the wizard puts anything it would
              otherwise delete.

  version.txt   which version of the wizard this is.


NOTHING IS EVER DELETED
-----------------------
Anything the wizard replaces goes to Cache\Trash or Backups\Archive first.
Empty Cache\Trash whenever you like.


SOMETHING WRONG?
----------------
Open the wizard and use Help > Report a bug, or look at Cache\logs\wizard.log.
