# ===========================================================================
#  GPU LOOKUP TABLE - graphics card name pattern -> tier
# ===========================================================================
#  Used by the machine profile system to pick Low / Medium / High for a
#  computer it has never seen. One rule per line:
#
#      pattern|tier
#
#  The pattern is matched against the card name Windows reports (for example
#  "NVIDIA GeForce GTX 1070" or "Intel(R) UHD Graphics 630"). * matches
#  anything, matching ignores upper/lower case, and THE FIRST MATCHING LINE
#  WINS - so specific rules must sit above general ones.
#
#  Tiers are judged for THESE emulators (GameCube/Wii/3DS/DS/Wii U/N64 on a
#  1080p TV), not for modern PC games:
#      low    = run at native resolution, favour speed
#      medium = 720p-class picture (the Quadro P2200 machine is the yardstick)
#      high   = full 1080p picture with anti-aliasing and filtering
#
#  A card matching no line falls through to the generation guesser built into
#  the scripts, which reads the model number and lands newer cards sensibly.
#  If the guess is ever wrong, add one line here - or just change the tier
#  line in that machine's file under profiles\machines\.
# ===========================================================================
