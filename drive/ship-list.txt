; ===========================================================================
;  WHAT AN UPDATE OWNS - the ship list                         (2026-10-10)
; ===========================================================================
;  Every file the public repo (github.com/Feirzen/retrobat-wizard) carries,
;  and so every file an update is allowed to write. Paths are relative to
;  _ClaudeWorkspace, with / between folders.
;
;    code   the update owns it, and replaces it whenever it differs
;    seed   the PERSON owns it. Written only when it is missing, never after.
;           "seed X <- Y" ships the file at Y in X's place, for a file whose
;           copy on this drive is personal (wizard.ini holds Steven's name).
;    skip   never shipped, even if a line above matches it
;
;  *  matches inside one folder, ** matches any depth.
;
;  ANYTHING NOT MATCHED HERE IS NOT THE UPDATE'S BUSINESS: saves, roms,
;  SaveBackups\ (except its buttons), archive\, _SAFE TO DELETE\, the machine
;  files for each computer, the profile, social\, logs, and the personal pack
;  (the Zelda and Pokemon collections, player-counts.ini).
;
;  Read by the publishing step, never by the drive at run time. The manifest
;  the drive reads is built from this list.
; ---------------------------------------------------------------------------
