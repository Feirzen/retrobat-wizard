# For the PC

Changes made from the cloud that have NOT been put on the drive yet.
The drive is the source of truth, so none of these go to the website or get
published until they've been applied on the PC and tried there.

How to use this folder (tell Claude on the PC):
"Apply the FOR-THE-PC notes from the retrobat-wizard repo to my 3.1 build."

Each change has two files:
- `<date>-<name>.md`: what it does, and each edit as "find this, replace with this".
  Works even if the PC copy has moved on since, because it matches text, not line numbers.
- `<date>-<name>.patch`: the same edit as a git patch, for when the files still match.

When a change is on the drive, add it to the Applied list below.
