RetroBat Wizard

A portable retro game setup built for party and co-op nights, mostly Nintendo, plus some silly classics. RetroBat runs the games. The wizard sets everything up for you, keeps it up to date with one button, finds your friends online, and gets netplay going without the headache.

Good to know

Online with friends. The wizard's Netplay tab walks you through it, one console at a time. NES, SNES and N64 have the least lag. GameCube and Wii go through Dolphin with a code you share. Everything else works through Parsec.

Profiles. Make one to add friends, see who is online and what they are playing, or play as a guest and nothing is sent at all.

Something broke, or want a game added? Use Report a bug or Suggest something on the wizard's Help tab.

This is a side project with no real online protection. Shared with other people who use the wizard: your profile name, picture, status, friends list and what you are playing. Nothing else leaves your drive. Only add games you own.

Five steps

Get started

  1. Download RetroBat (free). Straight from RetroBat's own GitHub, about 1.9 GB:
    Download RetroBat 8.2.1
    This is the full, standalone RetroBat for Windows: everything lives in one folder and runs from anywhere. If you have an external hard drive, this is a great use for it, because your games and saves go wherever the drive goes.
  2. Install it and open it once. Run the file you downloaded and pick a short folder like D:\RetroBat: not right at the top of the drive, no spaces, not in Program Files. Then double-click RetroBat.exe, let it finish starting up, set up your controller if it asks, and close it.
  3. Download the wizard installer and unzip it into your RetroBat folder, right next to RetroBat.exe.
    Download the installer
  4. Double-click INSTALL THE WIZARD.bat. It downloads the wizard and the ckau-book look the wizard is built for (a big one, 1 to 2 GB; press N if you would rather skip it), then asks a few quick questions (pick Quick setup if you are not sure). Everything can be changed later inside the wizard.
  5. Add games. Open the wizard's Games tab: add games you own from your computer, or grab free ones from the library.

Windows may warn about a downloaded script. Choose More info, then Run anyway. You never need a GitHub account.
