Retro gaming for game nights

RetroBat Wizard

A portable retro game setup built for party and co-op nights, mostly Nintendo, plus some silly classics. RetroBat runs the games. The wizard sets everything up for you, keeps it up to date with one button, finds your friends online, and gets netplay going without the headache.

Good to know

Online with friends. The wizard's Netplay tab walks you through it, one console at a time. NES, SNES and N64 have the least lag. GameCube and Wii go through Dolphin with a code you share. Everything else works through Parsec.

Profiles. Make one to add friends, see who is online and what they are playing, or play as a guest and nothing is sent at all.

Something broke, or want a game added? Use Report a bug or Suggest something on the wizard's Help tab.

This is a side project with no real online protection. Shared with other people who use the wizard: your profile name, picture, status, friends list and what you are playing. Nothing else leaves your drive. Only add games you own.

Five steps, about 20 minutes

Get started

  1. Get RetroBat. It is free, and it is what plays the games.
    • Click this button. The download is about 2 GB, so it takes a few minutes.
      Download RetroBat
    Already have RetroBat on this computer? Skip to step 3.
  2. Install RetroBat.
    • Open the file you just downloaded. It is in your Downloads folder.
    • A blue box that says Windows protected your PC? Click More info, then Run anyway.
    • When it asks where to install, leave it as it is (C:\RetroBat) and click Next.
    • If it shows a list of extras, tick Visual C++ and DirectX 9, then carry on.
    • When it finishes, open RetroBat once. Wait for its menu to show up, then close it.
    Want it on an external drive so it travels with you? Pick a folder on that drive instead, like D:\RetroBat.
  3. Get the wizard.
    • Click this button. It downloads a small zip file.
      Download the wizard
  4. Install the wizard.
    • Open your Downloads folder and double-click the zip file you just got.
    • Inside is one file, INSTALL THE WIZARD. Double-click it.
    • If Windows asks, click Run (or More info, then Run anyway).
    • A window with three bars opens. It finds RetroBat by itself. If it ever asks, point it to the RetroBat folder.
    • The wizard opens and asks a few questions. Pick Quick setup.
    • Leave the bars window open. It closes by itself when the last bar is done (that one is the new look, about 2 GB).
    Know what you want? Advanced setup lets you choose things like how hard the computer is pushed, where the buttons go, and controllers.
  5. Play.
    • Press PLAY in the wizard, or the Play icon it put on your desktop.
    • To add games, open the wizard's Games page: add games you own, or pick free ones from the library.

Something went wrong? Run the installer again: it carries on where it stopped. Its notes are in RetroBat\_Wizard\Cache\logs\install.log.
